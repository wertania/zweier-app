# Zweier – Flutter app

Android app for Zweier. See the [main README](../README.md) for features and setup.

- `lib/api/` – HTTP client for the backend
- `lib/state/` – app state (`provider`)
- `lib/screens/`, `lib/widgets/` – UI
- `lib/l10n/` – translations (`flutter gen-l10n` runs automatically on build)
- `assets/icon/` – launcher icon sources (`dart run flutter_launcher_icons` regenerates the Android icons)
